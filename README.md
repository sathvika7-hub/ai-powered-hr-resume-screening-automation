# ai-powered-hr-resume-screening-automation
An AI-powered HR automation that screens bulk resumes from Google Drive using Google Gemini AI to filter candidates based on required skills and abilities. Only qualified profiles are shortlisted and notified via Gmail. Built to automate high-volume applicant screening for HR teams.
